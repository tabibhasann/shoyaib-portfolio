# Shoyaib — Portfolio Website

Premium portfolio for Shoyaib (Abu Musa M.) — freelance editor, writer & digital marketer based in Dhaka, Bangladesh.

## Stack

- Plain static HTML/CSS/JS (no build step)
- GSAP + ScrollTrigger + Lenis (via CDN)
- Fraunces + Inter + Space Mono (Google Fonts)
- Warm editorial dark theme

## Structure

```
├── index.html              # Home — hero, work gallery, about, contact
├── css/style.css           # All styles
├── js/main.js              # Main page JS (cursor, lightbox, magnetic, etc.)
├── js/article.js           # Article/listing page JS
├── editing/
│   ├── index.html          # Editing landing
│   ├── video-editing.html  # Video editing gallery
│   └── static-design.html  # Static design gallery
├── writing/
│   ├── index.html          # Writing landing
│   ├── marketing-funnel.html
│   ├── reflection-2025.html
│   ├── stop-thinking-start-doing.html
│   └── what-is-mph.html
├── assets/                 # Images and videos
├── robots.txt
└── sitemap.xml
```

## Local Preview

```bash
python3 -m http.server 8123
```

Then open `http://localhost:8123`.
