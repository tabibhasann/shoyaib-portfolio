# Shoyaib — Portfolio Website

Portfolio for Shoyaib Raby — freelance editor, writer & digital marketer in Dhaka, Bangladesh. Live at https://shoyaibraby.com.

- **Content** (all text, articles, images, videos) is edited in Sanity Studio: https://shoyaib.sanity.studio. See [docs/EDITING-GUIDE.md](docs/EDITING-GUIDE.md).
- **Site** is built with [Astro](https://astro.build) from that content into plain static HTML, and published to GitHub Pages by GitHub Actions.
- **For developers and AI tools:** read [AGENTS.md](AGENTS.md) first.

## Run locally

```bash
npm install
npm run dev            # site at http://localhost:4321
npm --prefix studio install
npm run studio         # editing screen at http://localhost:3333
```
